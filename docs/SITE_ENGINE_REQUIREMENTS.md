# Μηχανή παραγωγής sites — Προδιαγραφές

**Έκδοση:** προσχέδιο 1 · 2026-07-28
**Σκοπός:** ορισμός του τι πρέπει να παράγει η μηχανή, με κριτήρια που **ελέγχονται αυτόματα** από το QA gate.

---

## 1. Το μοντέλο δύο σταδίων

| | **Στάδιο Α — Demo** | **Στάδιο Β — Production** |
|---|---|---|
| Για ποιους | και τους 6.463 leads | μόνο όσους απαντήσουν |
| Σκοπός | να πάρουμε απάντηση | να κατατάσσεται στη Google |
| Δομή | **μονοσέλιδο** + sitemap/robots | **πολυσέλιδο** αν χρειαστεί |
| Δεδομένα | τα 5 πεδία που έχουμε | + Google Places + στοιχεία πελάτη |
| Κόστος/site | ελάχιστο (~$0,01) | δικαιολογημένο (πληρώνει ο πελάτης) |
| SEO | τεχνική υγιεινή | πλήρες τοπικό SEO |

Το κόστος του εμπλουτισμού και του βάθους πληρώνεται **μόνο** για όσους δείξουν ενδιαφέρον.

---

## 2. Είσοδος

### Στάδιο Α (διαθέσιμα σήμερα)
`company` · `region` (νομός) · `phone` · `email` · `category` (417 μοναδικές ελληνικές περιγραφές NACE)

**Δεν υπάρχουν:** διεύθυνση, δήμος, ωράριο, φωτογραφίες, περιγραφή επιχείρησης.

### Στάδιο Β (μετά το «ναι»)
Τα παραπάνω **+ Google Places API**: διεύθυνση, δήμος, συντεταγμένες, ωράριο, κριτικές, φωτογραφίες
**+** ό,τι δώσει ο ίδιος ο πελάτης (υπηρεσίες, φωτογραφίες, ιστορικό).

---

## 3. Έξοδος και φιλοξενία

### Στάδιο Α — ένα Netlify site, φάκελος ανά επιχείρηση

```
demo.<domain>/                 ← ΕΝΑ Netlify site
  l-d-trading/index.html
  kafeneio-o-ilios/index.html
  ...
  robots.txt                   ← καθολικό Disallow
```

**Γιατί όχι ξεχωριστό site ανά πελάτη:** 6.463 sites σε έναν λογαριασμό Netlify είναι το κλασικό μοτίβο κατάχρησης — κίνδυνος αναστολής λογαριασμού και απώλειας των πάντων μαζί. Ένα site με φακέλους δεν έχει όριο, ανανεώνεται με ένα deploy και καθαρίζει εύκολα.

### Στάδιο Β — δικό του domain

```
<clientdomain>.gr/
  index.html               Αρχική
  ypiresies/index.html     Υπηρεσίες      (αν το βάθος το δικαιολογεί)
  epikoinonia/index.html   Επικοινωνία
  sitemap.xml · robots.txt
```

### Ευρετηρίαση

| | Στάδιο Α (demo) | Στάδιο Β (production) |
|---|---|---|
| `<meta name="robots">` | **`noindex, nofollow`** | `index, follow` |
| `robots.txt` | `Disallow: /` | κανονικό + sitemap |
| Σήμανση | διακριτικό «προεπισκόπηση» | — |

Το SEO **υπάρχει και φαίνεται** στο demo (schema, meta, δομή — ορατά σε όποιον κοιτάξει τον κώδικα), απλώς δεν ευρετηριάζεται. Τρεις λόγοι: 6.463 παρόμοιες σελίδες στο ίδιο domain είναι σήμα spam που βλάπτει το κύριο domain· ένα ευρετηριασμένο demo θα ανταγωνιζόταν αργότερα το πραγματικό site του πελάτη· και δημοσιεύονται στοιχεία υπαρκτής επιχείρησης που δεν έχει συμφωνήσει ακόμα.

## 4. Λειτουργικές απαιτήσεις — Στάδιο Α

| # | Απαίτηση | Έλεγχος |
|---|---|---|
| **D‑1** | Όλο το κείμενο στα ελληνικά | ανίχνευση ελληνικών χαρακτήρων |
| **D‑2** | Μηδέν placeholder / γενικόλογο κείμενο | λίστα απαγορευμένων φράσεων (ήδη στο QA gate) |
| **D‑3** | 3–5 εικόνες σχετικές με την **κατηγορία**, από Unsplash/Pexels | καταμέτρηση `<img>` + έγκυρα URLs |
| **D‑4** | Κάθε εικόνα με περιγραφικό ελληνικό `alt` που περιέχει keyword | κάθε `<img>` έχει μη κενό `alt` |
| **D‑5** | Φόρμα επικοινωνίας που **στέλνει πραγματικά** (Netlify Forms) | ύπαρξη `data-netlify="true"` + πεδίων |
| **D‑6** | Τηλέφωνο ως `tel:` και email ως `mailto:` | παρουσία συνδέσμων |
| **D‑7** | Sections με βάση την κατηγορία, όχι σταθερό πρότυπο | σύγκριση δομής μεταξύ κλάδων |
| **D‑8** | Ελάχιστο **300 λέξεις** πραγματικού ελληνικού κειμένου | καταμέτρηση λέξεων ορατού κειμένου |
| **D‑9** | Χωρίς οριζόντια κύλιση στα 375px | έλεγχος με Chromium (υπάρχει) |
| **D‑10** | Μηδέν σφάλματα κονσόλας / σπασμένα anchors | υπάρχει στο QA gate |

## 5. Απαιτήσεις SEO — μετρήσιμες

Αυτές παράγονται **ντετερμινιστικά σε κώδικα**, δεν ζητούνται από το μοντέλο.

| # | Απαίτηση | Κριτήριο επιτυχίας |
|---|---|---|
| **S‑1** | `<title>` | 50–60 χαρακτήρες · περιέχει επωνυμία + keyword κατηγορίας + περιοχή |
| **S‑2** | `<meta name="description">` | 150–160 χαρακτήρες · περιέχει keyword |
| **S‑3** | `<html lang="el">` | ακριβώς αυτό |
| **S‑4** | Ακριβώς **ένα** `<h1>` · ιεραρχία h2/h3 χωρίς κενά | ανάλυση δομής |
| **S‑5** | **JSON‑LD `LocalBusiness`** | έγκυρο JSON · `name`, `telephone`, `email`, `areaServed`, `@type` από την κατηγορία |
| **S‑6** | Open Graph | `og:title`, `og:description`, `og:image`, `og:url`, `og:type` |
| **S‑7** | `<link rel="canonical">` | απόλυτο URL Netlify |
| **S‑8** | `<meta name="viewport">` | present |
| **S‑9** | `robots.txt` + `sitemap.xml` | υπαρκτά, έγκυρο XML |
| **S‑10** | **Μοναδικότητα περιεχομένου** | ομοιότητα < 70% με άλλα sites της ίδιας κατηγορίας |
| **S‑11** | Σημασιολογικό HTML | `<header> <main> <section> <footer>` |
| **S‑12** | `<meta name="robots">` ανάλογα με το στάδιο | Α: `noindex, nofollow` · Β: `index, follow` |
| **S‑13** | **Base URL ως παράμετρος** — κανένα καρφωμένο domain | `canonical`, `og:url`, `sitemap.xml`, JSON-LD παράγονται από μία μεταβλητή |

**S‑10 είναι κρίσιμο:** 6.463 όμοια sites σε `*.netlify.app` = near‑duplicate content. Η μηχανή πρέπει να παράγει ουσιαστικά διαφορετικό κείμενο ανά επιχείρηση, όχι παραλλαγές του ίδιου προτύπου.

### Στάδιο Β επιπλέον
`LocalBusiness` με `address` + `geo` + `openingHours` · keywords σε επίπεδο **δήμου** · ενσωμάτωση χάρτη · περιεχόμενο ανά υπηρεσία.

## 6. Μη λειτουργικές απαιτήσεις

| # | Απαίτηση |
|---|---|
| **N‑1** | 50 sites/ημέρα χωρίς χειροκίνητη παρέμβαση |
| **N‑2** | Καμία εξάρτηση από Claude Code στη γραμμή παραγωγής |
| **N‑3** | Τρέχει σε Docker, ίδια συμπεριφορά σε macOS και Windows |
| **N‑4** | Ιδεατά < $0,02 ανά demo site |
| **N‑5** | Ιδempotent: δεν ξαναφτιάχνει site που υπάρχει ήδη στο repo |
| **N‑6** | **Ομαλή υποβάθμιση**: αν πέσει Unsplash/Places/Netlify, το site παράγεται και μπαίνει στην ουρά με σημείωση — ο lead δεν χάνεται ποτέ |
| **N‑7** | Κάθε στάδιο ελέγχεται μεμονωμένα (χωριστά τεστ ανά expert) |
| **N‑8** | **Μετάβαση Α→Β χωρίς σπασμένους συνδέσμους**: όταν το site φύγει στο δικό του domain, μπαίνει `301` από τη διεύθυνση demo — τα emails που έχουν ήδη σταλεί δείχνουν εκεί |
| **N‑9** | Ένα deploy ενημερώνει πολλά sites χωρίς να ξαναχτίζει τα υπόλοιπα |

## 8. Εκκρεμότητες πριν την υλοποίηση

| Τι | Κατάσταση |
|---|---|
| `NETLIFY_ACCESS_TOKEN` | ❌ άκυρο (401) — χρειάζεται νέο |
| Domain για τα demo (`demo.<domain>`) | ⬜ δεν έχει επιλεγεί |
| **Αναδιάρθρωση `netlify-deployer.js`** | ⚠️ χτίστηκε για ένα site **ανά πελάτη** — πρέπει να γίνει ένα site με φακέλους (απόφαση 2026-07-28) |
| Κλειδί Unsplash ή Pexels | ⬜ δεν υπάρχει |
| Κλειδί Google Places + λογαριασμός χρέωσης | ⬜ δεν υπάρχει (για Στάδιο Β) |
| `GITHUB_TOKEN` + `SITES_REPO` | ⬜ δεν υπάρχει |
| Μοντέλο για το κείμενο | ⬜ απόφαση (DeepSeek ή κάτι δυνατότερο στα ελληνικά) |
| Διόρθωση αντιστοίχισης πεδίων leads | ❌ **μπλοκάρει τα πάντα** — 0 από 6.463 leads περνούν σήμερα |
